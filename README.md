To run the project localy

1. Clone the repository

```bash
git clone https://github.com/reffy33/food-journal-app
```

2. Install the dependencies (the project uses pnpm as package manager)

```bash
cd food-journal-app
npm install
```

3. Run the project

```bash
npm run start
```
